# Security Policy

This repository is primarily educational documentation and templates.

## Reporting a Security Issue

If you discover a security issue in the repository itself, please avoid publishing sensitive exploit details in a public issue. Contact the repository maintainer privately through the contact method listed on the GitHub repository.

Do not include passwords, API keys, private tokens, or other secrets in issues or pull requests.

## For Projects Using This Guide

Security should be considered throughout the lifecycle, not only immediately before launch.
