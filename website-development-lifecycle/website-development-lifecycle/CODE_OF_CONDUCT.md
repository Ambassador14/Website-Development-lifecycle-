# Code of Conduct

## Our Standard

We want this project to be welcoming, respectful, and useful to everyone.

Examples of expected behavior:
- Be respectful and constructive.
- Assume good intentions.
- Focus criticism on ideas and contributions, not people.
- Help beginners learn.
- Respect different backgrounds and perspectives.

Unacceptable behavior includes harassment, personal attacks, discrimination, threats, or deliberate disruption.

Maintainers may remove contributions or restrict participation when necessary to keep the project safe and constructive.
