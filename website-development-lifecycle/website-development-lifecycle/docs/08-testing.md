# 8. Testing & Quality Assurance

A website is not finished because it works on the developer's computer.

## Functional testing
Verify that features work as intended.

## Responsive testing
Test mobile, tablet, and desktop layouts.

## Browser testing
Check major supported browsers.

## Performance testing
Check:
- Page load speed
- Image sizes
- JavaScript performance
- API response times

## Security testing
Check:
- Authentication
- Authorization
- Input validation
- Session management
- Sensitive data exposure
- Dependency vulnerabilities

## Accessibility testing
Check:
- Keyboard navigation
- Color contrast
- Screen-reader compatibility
- Form labels
- Alternative text

Also check broken links, forms, error handling, SEO, database operations, and third-party integrations.

Record defects, fix them, and retest.
