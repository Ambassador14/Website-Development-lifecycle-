# 4. UX/UI Design

Design the experience before building the interface.

## UX — User Experience
Focus on:
- User journeys
- Usability
- Navigation
- Information hierarchy
- Accessibility
- Interactions

## UI — User Interface
Focus on:
- Colors
- Typography
- Buttons
- Forms
- Icons
- Spacing
- Layouts
- Components

## Typical flow

```text
User Flow → Wireframe → Prototype → Visual Design → Review → Developer Handoff
```

Design for desktop, tablet, and mobile.

Before development, confirm that the design solves the intended user problem.
