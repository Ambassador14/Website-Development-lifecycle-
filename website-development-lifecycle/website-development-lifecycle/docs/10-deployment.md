# 10. Deployment

Move the website from development or staging into production.

## Before deployment
Check:
- Domain
- DNS
- SSL/TLS
- Environment variables
- Database
- Backups
- Production configuration
- Analytics
- Error monitoring

## Deployment flow

```text
Development → Testing → Staging → Final Review → Production
```

After deployment, perform a smoke test of the most important functions.

Examples:
- Homepage loads
- Login works
- Main forms work
- Database operations work
- Critical APIs respond
- HTTPS works
