# 6. Technical Planning

Decide how the website will be built.

## Technology choices

### Frontend
Examples:
- HTML
- CSS
- JavaScript
- React
- Vue
- Next.js

### Backend
Examples:
- Node.js
- Python
- Java
- PHP
- Go

### Database
Examples:
- PostgreSQL
- MySQL
- MongoDB
- SQLite

Choose technologies based on project requirements, team skills, budget, scalability, security, and maintainability.

## Also plan
- Hosting
- Domain and DNS
- SSL/TLS
- APIs
- Authentication
- Authorization
- Database architecture
- File storage
- Backups
- Monitoring
- CI/CD
- Security controls
- Git workflow

Never commit passwords, API keys, tokens, or database credentials to Git.
