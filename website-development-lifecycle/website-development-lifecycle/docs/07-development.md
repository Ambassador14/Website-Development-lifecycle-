# 7. Development

Turn the approved design and technical plan into a working product.

## Frontend
Build:
- Pages
- Components
- Navigation
- Forms
- Responsive layouts
- Interactions

## Backend
Build:
- APIs
- Authentication
- Business logic
- Database operations
- File handling
- Integrations

## Good development practices
- Use Git
- Make meaningful commits
- Use branches
- Review code
- Use environment variables for secrets
- Reuse components
- Validate input
- Handle errors
- Document important decisions
- Write tests where appropriate

Keep development aligned with the requirements rather than adding features simply because they are technically interesting.
