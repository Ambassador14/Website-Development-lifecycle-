# 9. User Acceptance Testing

User Acceptance Testing (UAT) verifies that the product meets real-world needs.

## UAT questions
- Does the website solve the intended problem?
- Can users complete important tasks?
- Is anything confusing?
- Are important requirements missing?
- Does the website match the approved scope?

## Process

```text
Prepare scenarios
      ↓
Users/stakeholders test
      ↓
Record feedback
      ↓
Fix issues
      ↓
Retest
      ↓
Approval
```

UAT is different from technical QA: QA asks whether the system works correctly; UAT asks whether the solution is acceptable for its intended use.
