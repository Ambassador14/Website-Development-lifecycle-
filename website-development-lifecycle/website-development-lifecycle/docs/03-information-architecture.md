# 3. Information Architecture

Information architecture defines how information and pages are organized.

## Create
- Sitemap
- Navigation structure
- Page hierarchy
- User flows
- Content structure

### Example

```text
Home
├── About
├── Services
│   ├── Service 1
│   ├── Service 2
│   └── Service 3
├── Blog
├── Contact
└── Account
    ├── Login
    ├── Register
    └── Dashboard
```

A good structure helps users understand where they are, where they can go, and how to complete important tasks.
