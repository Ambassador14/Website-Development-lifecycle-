# Contributing

Thank you for helping improve this repository.

## How to Contribute

1. Fork the repository.
2. Create a topic branch.
3. Make your changes.
4. Check Markdown links and formatting.
5. Commit your changes with a clear message.
6. Open a pull request.

## Good Contributions

Useful contributions include:
- Fixing inaccurate or unclear explanations
- Adding beginner-friendly examples
- Improving templates
- Adding missing lifecycle guidance
- Fixing broken links
- Improving accessibility and readability

## Writing Guidelines

- Prefer plain language.
- Explain technical terms when first introduced.
- Keep sections focused.
- Use examples where they improve understanding.
- Avoid unnecessary jargon.
- Keep advice practical and technology-neutral where possible.

## Pull Requests

Please explain:
- What changed
- Why it changed
- Which files were affected
- Any limitations or follow-up work

Be respectful and constructive when reviewing contributions.
